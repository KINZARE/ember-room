# LOW EMBER

LOW EMBER is a fictional premium hospitality portfolio concept: a late-night open-fire kitchen, cocktail bar and listening room in Rotterdam.

The public site is intentionally presented as a complete venue experience so it can be used as a sales/demo asset. No customer reviews, press quotes, awards, operational booking integrations or other third-party proof are fabricated.

## Stack

- Next.js App Router
- React
- TypeScript
- CSS
- Vercel

Reservation interactions are client-side only and do not transmit guest data.
